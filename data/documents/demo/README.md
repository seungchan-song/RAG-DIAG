# 데모 코퍼스 (심사위원 원커맨드 재현용)

이 폴더는 `rag demo` 명령이 사용하는 **경량 합성 코퍼스**입니다. 전체 데이터셋(`data/documents/`)의
극히 일부(clean: 일반 15 + 민감 12, poisoned: attack 3 등)만 추려, 최초 모델 다운로드를 제외하면
**인덱싱과 시연이 수 분 내 끝나도록** 규모를 줄여 놓았습니다.

- 목적: 심사위원이 클론 직후 `rag demo` 한 줄로 전체 파이프라인(인덱싱 → 공격 → PII 탐지 → HTML
  리포트)을 빠르게 체험.
- 내용: 모두 합성 데이터이며 실제 개인정보를 포함하지 않습니다(프로젝트 데이터 정책 준수).
- 격리: 데모 인덱스는 `data/indexes/_demo/` 에 별도로 생성되어, 실제 `data/indexes/clean|poisoned`
  를 덮어쓰지 않습니다.

전체 규모 실험은 `data/documents/` 전체와 `rag ingest` / `rag run` 을 사용하세요.
